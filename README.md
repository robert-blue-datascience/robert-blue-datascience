**Data Advocate | Founder, Juniper**

I help companies build the data foundations that make AI trustworthy. Through Juniper, I bring hands-on data engineering, fractional data leadership, and agentic AI design to organizations (primarily in energy and industrial sectors) where bad data has real operational cost.

My approach starts with methodology, not tools. Every engagement opens with the Core Four Gate: four questions that determine whether work should exist before a dollar is spent. Every system I build follows a [multi-agent development workflow](https://github.com/robert-blue-datascience/ai-dev-workflow-showcase) with automated quality gates, independent review, and security integration.

I'm an active member and speaker at **SPE/DSATS**, **IADC**, and **PPDM**, and my research on data quality foundations for trustworthy AI has been submitted to **URTeC 2026**.

## Methodology

I bring a methodology, not just skills. Two frameworks define how I work:

**The Core Four Gate.** A decision framework that runs before any new capability is designed. Four questions: Is there a real problem with a real owner? Can a human do this with the data as-is? Does the solution create more value than it displaces? Can we define what success AND failure look like? A "no" doesn't kill the idea; it produces a preparatory project that converts the "no" into a "yes."

**The Agentic Development Workflow.** A multi-agent development methodology with tiered change classification, automated quality gates, independent cold review, hallucination defense, and security integration. It lets a solo engineer operate with the rigor of a well-run engineering team.
